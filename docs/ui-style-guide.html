Crash recovery prompt

Two shapes of the same card. With a resume there is one filled action and the terminal choices are behind the overflow. Without one there is no filled action at all: the only remaining answers close the turn out, and the card states why resuming is not on offer.

Picked up after a crash

Reading a file was interrupted before it finished

Nothing that could have changed anything outside Damaian was in flight, so this turn was marked safe to pick up again. It has not run yet — continuing sends the same request to the model again.

After a crash
