Crash recovery prompt

Two shapes of the same card. With a resume there is one filled action and the terminal choices are behind the overflow. Without one there is no filled action at all: the only remaining answers close the turn out, and the card states why resuming is not on offer. The spend line appears only when the turn had recorded usage — absent, never a zero, which would read as a crash that was free.

Picked up after a crash

Findings panel

A session dock between the chat log and the composer, opened from a Findings n toggle that is hidden while the session has none (spec 22). Grouped by source, then file; file paths truncate from the left. Only an open finding can be selected. A stale one keeps a disabled checkbox and says why. One filled action, Fix selected (n); Dismiss and Restore are quiet. In the app the panel is capped at min(320px, 36vh) and its list scrolls; the cap is lifted here so both rows show.

Settings › General. Consecutive list entries from one source share a row. A refused request is shown by key and class only, never by value, on a row under its rule.
