  • A command is one row. It shows the command, an exit mark, and its output folded away. When the command waits for approval, the row is replaced by the approval card, in the same place.
  • The working directory appears only when it differs from the repo root. Empty STDOUT/STDERR is collapsed to "no stderr".

Only shown when an update is available. "Check for updates" moves to Settings → General.
  • Workers: hidden while a project has none. When workers exist, the row shows the most urgent dot (needs you › running), a needs-you badge and a "N running" count. The board stays reachable from the project ⋮ menu.
  • Project row: the folder icon is replaced by the disclosure caret on the left, so you click the place you look at. "New session" gets a compose icon so it no longer looks like "Add folder" (folder-plus). Both, plus ⋮, show on hover or focus only (opacity, so Tab still reaches them, per §4).
  • Brand: logo and name only. The current folder is already shown three times: the project row, the header and the repo bar.
  • Session rows get a muted relative time, so you can tell which conversation is the live one. Optional, and my suggestion.

  • Header: one borderless 28px icon style, each with a tooltip. Symbol search gets </> instead of a typed {}, and the terminal gets >_ instead of a box that reads as a window. The pressed state (terminal open) keeps the accent tint.
  • Context is turn state rather than a tool, so it sits apart. It shows how full the context is, which is what you'd glance at it for, and opens the same panel. The meter is my suggestion; if the number isn't cheap to show, it stays the word "Context", unboxed.
  • Composer: "Code" and "Default" get muted labels (Mode, Effort). The value stays the strong part, per §3 .btn-trigger. Attach becomes a paperclip, so the window no longer has three different "+" buttons.
