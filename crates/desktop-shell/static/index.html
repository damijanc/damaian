User configuration

Repository roots

A root is a project inside this repository. Damaian runs a command from the root that owns it. Add, remove and undo write to .damaian/config.conf in the repository — that file is in your working tree, so Git shows it.

Language servers

Add language_server.<language>=<command> to your user configuration to get exact symbol locations. A repository cannot set this key. A server starts on the first symbol lookup and stops after ten idle minutes or when Damaian quits.

Checkpoints

One checkpoint per turn for this repository, newest first. Checkpoints cover Damaian's own changes — files from patches you applied and files an approved command changed. They are session recovery, not version control, and no substitute for a commit.

MCP Servers

Connect local (stdio) or remote (HTTP) Model Context Protocol servers. Their tools are offered to the assistant alongside the built-in ones. Requires a model provider with native tool-calling enabled.

Hooks

A hook is a program you configure to check a lifecycle step — a tool call, a patch apply, a check, or the start or end of a session. It answers with a verdict: allow, warn, ask for approval, or deny. It can never grant more than your mode and permission profile already allow. A hook this repository defines does not run until you review it, and stops running if it changes.
